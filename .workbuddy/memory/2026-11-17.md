# 2026-11-17

## MagicShell：自建 PowerShell 终端工作台（首个可用版本）

需求：类似 PowerShell 的终端，但增强 4 点 —— 背景色可改 / 分组（点一个显示整组 shell）/ 复制全部文本 / 标题栏图钉置顶当前组。

技术选择：Electron 35 + xterm.js 6 + node-pty 1.1（ConPTY）。选它而不是 WPF/自研 VT 解析，是因为能拿到真实 PowerShell 交互（补全、颜色、Ctrl+C）且渲染只写前端。

关键结论/坑：

- `node-pty@1.1.0` 自带 N-API 预编译产物（`prebuilds/win32-x64`），可直接在 Electron 35 用，**不需要** node-gyp/MSVC。验证方式：`ELECTRON_RUN_AS_NODE=1 electron.exe -e "require('node-pty')"`。
- electron-builder 默认会 `@electron/rebuild` 原生模块 → 本机缺 Spectre 库报 MSB8040。加 `-c.npmRebuild=false` 跳过。
- electron-builder 下载 winCodeSign/NSIS 走本机代理会 502，`dist` 单文件打包失败。改用 `tools/package.mjs` 手工组装 `dist/MagicShell/`（复制 electron/dist + resources/app），已验证 9/9 自检通过。
- **本机环境变量 `ELECTRON_RUN_AS_NODE=1` 是全局的**（WorkBuddy 自己注入），命令行启动 Electron 必须 `env -u ELECTRON_RUN_AS_NODE`，否则 app 报 `requestSingleInstanceLock of undefined`。
- xterm `.xterm-viewport` 默认纯黑背景，浅色主题会在面板底部露出一条黑线 → CSS 置透明，由 `.pane` 背景兜底。
- 3 个终端用 2x2 会留空格子，改成「左一占满两行 + 右侧两个叠放」（gridSpec.spanFirst）。
- WebGL addon 可用（`@xterm/addon-webgl`），失败回退 DOM 渲染。

实现要点：
- 分组 = 一块 `.stage`，组内终端 CSS Grid 平铺；非活动组 `display:none` 但保留终端实例（切组不丢回滚缓冲）。
- 恢复上次分组时采用懒启动：只有激活组立刻 spawn PTY，其它组首次进入才 spawn。
- 图钉是「分组」属性：点任意面板图钉 = `win.setAlwaysOnTop(true)`；切到未置顶组自动取消。
- 复制全部：遍历 `term.buffer.active` 行 `translateToString(true)`，走主进程 clipboard；支持单窗 / 整组。
- 主题：JS 算明暗后写 CSS 变量（--ui-*），并同步 `nativeTheme.themeSource` 让 Windows 标题栏跟着变。

自检工具在 `tools/`（CDP 驱动）：`probe.mjs` 抓状态+截图、`e2e.mjs` 功能、`e2e-input.mjs` 真实键盘/快捷键、`package.mjs` 打包、`docs-shots.mjs` 文档截图。

后续可做：多窗口浮层模式、分隔条拖拽、自定义图标、macOS/Linux 适配。

## 追加：终端独立配色 + 独立标题

需求：背景色原来只能改整窗，要能只改某个 shell；并且能一键应用到全部 shell；每个 shell 还要能起自己的名字。

实现：
- `meta.bg` / `meta.fg`（单个终端覆盖）+ `settings.paneBg` / `settings.paneFg`（全体终端默认）。颜色优先级：pane 覆盖 → 全局终端默认 → 窗口背景。
- 文字色按 WCAG 相对亮度自动纠正：`contrast(bg, fg) < 3.2` 时换成 `#1f2328`/`#e6edf3`；ANSI 调色板也分深浅两套（`ANSI_DARK`/`ANSI_LIGHT`），避免浅底白字。
- 关键技巧：自定义底色会把标题栏/工具按钮上沿用全局 `--ui-*` 变量而糊掉。做法是在 `.pane` 元素上 scoped 覆盖 `--ui-text/--ui-dim/--ui-elev/--ui-bg/--ui-border/--ui-hover`，跟着底色重算，子元素 CSS 不用改。
- 新增「终端外观」居中弹层（#look）：9 套预设 + 任意取色 + 文字色自动/自定义 + 预览 + 「应用到所有终端」（写入 settings.paneBg 让新终端也继承）；抽屉里加了「全部终端跟随窗口」一键回退。
- 标题：`meta.customTitle` 为真时忽略 `term.onTitleChange` 与 spawn 后的自动改名；双击标题栏内联 input 编辑（Enter 保存/Esc 取消/清空恢复自动），右键菜单也有入口。
- 持久化：panes 增加 `fg`、`custom` 字段，restore 时回填。

坑：
- `input[type=color]` 原生内部有白/黑描边，需 `::-webkit-color-swatch-wrapper{padding:0}` + `::-webkit-color-swatch{border:none;border-radius:4px}` 才干净。
- 打包目录被正在运行的 exe 锁住时无法整体替换：直接覆盖 `dist/MagicShell/resources/app/src/` 即可（应用代码非 asar，重启即生效），不必删目录。
- 环境里的 safe-delete 钩子对整目录 `rm -rf` 会走回收站并 `SAFE_DELETE_FAIL_CLOSED`；逐文件 `find -delete` 可绕过，但被映射的文件仍报 busy。
- 单实例锁按 userData 区分，开发/测试要另起实例就加 `--user-data-dir`，否则会因用户已开着的 exe 直接退出。
- 自检脚本更新：新增 `tools/e2e-look.mjs`（10 项：改名/Esc/清空恢复/shell 不覆盖/单窗配色/浅底深字/应用到全部/重载恢复），`e2e-input.mjs` 里旧的 `.ctx-swatches` 断言改成走弹层。

## 追加：自由拖动/缩放 + 自动排列下拉 + 菜单内连续换色

需求：子窗口能改位置和大小；工具栏加「自动排列」下拉（几个常见布局）；`…` 菜单里点背景色不要关菜单。

实现：
- 布局模型从 CSS Grid 换成「矩形百分比」：每个终端 `meta.rect = {x,y,w,h}`（0~1 相对舞台），DOM 结构变成 `stage > .pane-slot > .pane`，槽定位、终端本体 `inset:4px` 形成窗间距；窗口缩放时百分比自动等比跟随，无需重算。
- `computeLayout(key, n)` 生成 7 种预设：auto / cols / rows / grid2 / grid3 / main-left / main-top；`gridRects()` 让最后一行不足时自动拉宽填满，避免空格子。auto：1 铺满、2 左右、3 左大右两叠、其余按 √n 网格。
- 拖标题栏移动（pointerdown → window pointermove/up，rAF 合并写入），8 个 `.pane-grip` 拖边/角缩放；边缘互吸（8px 阈值，包含「我的右边贴你的左边」这类候选）、夹在舞台内、最小 150×80px；拖动时 body cursor 固定为 grabbing/resize，松手 persist + fit。
- 任何手动拖动/缩放都会把该分组标为 `layout.custom = true`：此时新开终端走 `carveRectForNew()`（把面积最大的窗对半劈开），不推翻用户已摆好的位置；选预设则回到 `custom = false`，增删终端自动重排。
- 舞台加了 `--stage-bg`（深色系用 mix(bg,#fff,0.07) 而不是调暗——深色底下调暗几乎看不见），`--pane-shadow` 让自由摆放/重叠时能看出边界。
- 工具栏「排列」下拉复用 `#ctx-menu`，每项带一张按预设实时画的小示意图 SVG + 当前项 ✓，另有「应用到全部分组」。
- `openPaneMenu` 里插入 `renderPaneBgPicker()`：5×2 色块 + 「跟随默认」链接，点色块只 `setPaneLook` 并刷新选中环，不调 `closeCtxMenu()`（`openMenu` 本来只给 ctx-item 挂关闭，render 项天然不关）。

坑：
- 自检里 `e2e.mjs` 原来的 grid 断言（`gridTemplateColumns` 数量）失效，改成按 rect/包围盒断言；同时要在第一步清掉历史 pane 配色与 custom 布局，否则会被上一轮测试状态影响。
- 自定义布局下删终端会留空洞（不自动补位），选一次预设即可复位——这是有意的取舍。
- 新增 `tools/e2e-layout.mjs`（10 项：7 种预设几何、拖动、边界夹取、缩放、最小尺寸、劈窗新增、菜单连续换色、下拉项/图标/当前标记、点预设生效、持久化）。
